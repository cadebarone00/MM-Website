# Historical score sources

These files are preserved with the import tooling as immutable, human-auditable
maps of the original workbooks. They are not application data entered by
clients.

## 2026 Maroon Masters Player Round Map

`2026_Maroon_Masters_Player_Round_Map.csv` is the authoritative lookup for
each player's eight 2026 rounds: source sheet, format, partner, opponents,
scorecard block, and exact score cells. It must be used with the original
`2026 Maroon Masters (3).xlsx` workbook when reconciling Mission Hills.

Alternate Shot rows identify a shared team scorecard. Those scores belong in
the team-hole archive, rather than being counted twice as individual player
statistics. The player archive can still list the round for each partner by
joining to that team record.
