# Expo Tourneys feature review

Review started 2026-11-25. The first native slice reads the existing account-scoped Tourneys endpoint and displays tournament names, course, dates and past history. It adds no writes, new provider or payment flow. Later create, join, public discovery, invitations, scoring and organizer flows need their own scope assessment as implemented. Deployment and real-phone verification are outstanding; accountable owners, audience, markets, retention, vendors and professional reviewers remain unassigned.

All categories in FEATURE_COMPLIANCE_CHECKLIST.md remain **review_required**. Engineering must verify bearer authentication, account switching, server authorization, visibility, failure handling and data minimization. Privacy, personal data, retention and deletion, organizer responsibilities, minors, user-generated content and public sharing need policy and professional assessment. Code, fonts, assets and golf content require intellectual-property and dependency rights review. Payments, subscriptions, advertising and sponsorship are not introduced in this slice, but applicability remains unassessed. Platform/provider rules and qualified legal review remain unresolved. This record does not authorize release.

2026-11-25 scope update: native code lookup, joining and member overview send a code and optional handicap to the existing tournament handlers via app routes. Joining changes tournament membership and stores the handicap through existing server behavior. Verify account authorization, code access, membership and handicap validation, retention and organizer access; these remain review_required. No new payment, advertising, sponsorship or subscription flow is introduced. Server deployment and real-device checks are outstanding.

2026-11-25 detail update: the member-only overview displays saved player names, standings, tee groups and cut status using shared calculations; refresh re-reads the existing member endpoint. Verify event membership, visibility, participant data handling and accuracy on device. The existing privacy, security, retention, organizer, platform and professional review findings remain review_required.

2026-11-25 public discovery update: search queries and optional dates go to the existing public search; selected events use the sanitized spectator endpoint, exposing public player names and scores but no member tee sheets or join code. Verify visibility enforcement, public participant data and privacy choices, retention, organizer responsibility, minors, IP in golf data, security and platform rules. Payments, subscriptions, advertising and sponsorship were not introduced; applicability remains review_required. Professional review, deployment and phone checks remain outstanding.

2026-11-25 creation update: organizers submit tournament name, participation, handicap and course/tee/date selections to the existing server handler; creation persists event and participant data and generates a shareable code. Course searches invoke the existing course provider and may return provider attribution. Verify organizer authorization, course content rights, provider terms, privacy and personal data, code sharing, retention/deletion and security. No payment, subscription, advertising or sponsorship is added; applicability remains review_required. Store rules and qualified legal review remain outstanding.

2026-11-25 scoring update: signed-in members send hole scores, assigned-player attestations and card submissions to the existing authenticated tournament endpoint. These writes persist personal scoring data; they require network acknowledgement and have no offline queue. Verify player and attester authorization, scoring consistency, disputes, failure/retry behavior, account isolation, retention, deletion, organizer access and device behavior before release. Privacy, personal data, security, minors, platform rules and professional legal review remain review_required; payments, subscriptions, ads and sponsorship are not introduced by this slice and applicability remains unassessed.

2026-11-25 organizer controls update: the event organizer may share a join code, change spectator visibility and player sharing, set or remove cuts and end the event using existing server authorization. Public visibility can expose participant names and standings; verify disclosure, access controls, organizer authority, public/linked sharing, cut correctness, retention and ended-event behavior. Privacy, personal data, security, organizer responsibility, minors, platform rules, IP, retention, professional review and the applicability of payments, subscriptions, ads and sponsorship remain review_required. Server deployment and device checks are outstanding.

2026-11-25 tee-sheet update: organizers edit player grouping, tee times and starting holes via the existing server-authorized handler. Verify organizer-only authorization, assignment integrity, attestation effects, visibility, concurrent edits and device accessibility. Privacy, personal data, retention, security, organizer responsibility, platform and legal review remain review_required. No payment, subscription, advertising or sponsorship was introduced; applicability remains unassessed.

2026-11-25 invitation and PDF update: a pasted first-party invitation URL carries a bearer secret to the existing preview/accept handler; a net invite may collect handicap. Verify invite token handling, recipient identity and account linking, document access and public-storage exposure, privacy notices, retention, organizer responsibility, content rights, moderation, security, minors and platform rules.
