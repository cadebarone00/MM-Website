Course Library
==============

Courses are maintained manually. Add a course by name, then open Review / edit tees.
Each saved course card also has Import CSV and a downloadable template.

CSV format: one row per tee/hole. Required columns: tee_name,hole.
Optional: par,yardage,rating,slope,color (hex such as #800020).
Blank cells preserve existing values; missing values on new tees remain blank.
Matching tee names (case-insensitive) update in place and retain IDs.
New names add tee sets; omitted tee sets remain saved. Imports unlock affected
tees for review. Verify yardages and ratings before saving and locking for play.
CSV does not rename or duplicate the course. GolfCore integration is removed.
