# Accessibility Statement — Draft

**DRAFT — NOT EFFECTIVE**

The Maroon aims to make its website and tournament experiences usable by people with disabilities.

Current development practices should include, where practical:

- keyboard navigation;
- visible focus states;
- semantic headings and controls;
- text alternatives for meaningful images;
- sufficient color contrast;
- readable responsive layouts;
- labels/instructions for forms;
- avoiding color as the only indicator of status;
- accessible error messages;
- testing common user flows with browser accessibility tooling.

This statement should not claim a specific conformance level until an accessibility review supports that claim.
