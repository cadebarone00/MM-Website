# Cookie & Similar Technologies Policy — Draft

**DRAFT — NOT EFFECTIVE**

## Current Position

The Maroon requires certain session, authentication, security, and application-state technologies to operate.

As of a repository scan on 2026-09-30, no PostHog, Google Analytics/gtag, or Sentry integration was identified. This is not proof that production sets no nonessential cookies. Perform a browser/network/storage audit before publishing this policy.

## Categories

### Strictly Necessary

May include technologies used for:

- authentication and sessions;
- fraud/security protection;
- routing and load balancing;
- preserving essential account or tournament state.

These generally cannot be disabled without breaking requested service functionality.

### Preferences

Future optional preference storage may remember user choices. Inventory before use.

### Analytics

Not represented as active until an analytics provider is actually implemented and reviewed.

### Advertising / Targeting

Not represented as active until advertising/targeting technology is actually implemented and reviewed.

## Consent / Preferences

If nonessential cookies or similar technologies are introduced, implement a preference system appropriate to the jurisdictions served.

Where consent is required:

- optional tracking must remain off until consent;
- users must be able to reject optional technologies;
- users must be able to reopen and change preferences;
- consent records should be versioned/auditable;
- withdrawing consent should be as practical as granting it.

## Audit Table

Before publication, maintain a current table containing:

- cookie/storage key;
- provider;
- category;
- purpose;
- first/third party;
- lifetime;
- whether required;
- jurisdictions requiring consent;
- link to provider documentation.
